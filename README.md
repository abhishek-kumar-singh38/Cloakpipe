# CloakPipe

## Defensive Host and Network Transformation Research Harness

CloakPipe is an educational, authorization-first security engineering toolkit for studying how defensive controls normalize and detect harmless test markers. It produces **inert canary artifacts only**:

- A benign C diagnostic program that prints a fixed CloakPipe canary.
- A structured corpus of URL, Base64, hexadecimal, JSON, and form-encoding representations of that canary.
- Machine-readable metadata for comparing normalization and detection behavior in a lab.

It does **not** generate shellcode, exploits, loaders, persistence, memory execution stagers, stealth executables, or deployable bypass payloads.

## Safety boundary

Run this project only against systems you own or have explicit written permission to test. The network corpus is intentionally limited to a fixed, non-functional canary. The host module creates a transparent diagnostic program and never allocates executable memory or executes generated bytes.

## Requirements

- Python 3.10 or newer
- Optional: `gcc` or `clang` for the host compilation check
- No third-party Python packages are required

## Quick start

```bash
cd CloakPipe
python3 cloakpipe.py network --output output/network-corpus.json
python3 cloakpipe.py host --output output/host-canary.c
python3 cloakpipe.py host --output output/host-canary.c --compile
```

The generated files are safe lab artifacts:

- `output/network-corpus.json` contains representations of the fixed canary.
- `output/host-canary.c` contains a readable C program that prints the canary.
- `output/host-canary` is produced only when `--compile` succeeds and is a normal diagnostic executable.

## CLI reference

### Generate the network corpus

```bash
python3 cloakpipe.py network \
  --output output/network-corpus.json \
  --label waf-normalization-study
```

The corpus includes deterministic, labeled records. Each record states the representation family and the expected decoded canary. It is designed for offline parser and normalization tests, not for sending requests to third-party services.

### Generate the host canary source

```bash
python3 cloakpipe.py host --output output/host-canary.c
```

### Compile the host canary

```bash
python3 cloakpipe.py host \
  --output output/host-canary.c \
  --compile \
  --compiler gcc
```

The compiler command uses conservative diagnostics and optimization settings. The generated program has no network behavior, no input handling, and no memory execution behavior.

### Clean generated artifacts

```bash
python3 cloakpipe.py clean --output-dir output
```

Cleanup refuses to operate outside a directory explicitly named `output`, and it removes only known generated filenames. Use `--yes` for non-interactive execution:

```bash
python3 cloakpipe.py clean --output-dir output --yes
```

## Research ideas

This harness can support defensive questions such as:

1. Which parser layers normalize percent encoding consistently?
2. Which logging pipeline preserves representation metadata?
3. Does a scanner report the same fixed canary after JSON, form, or URL decoding?
4. Can a host monitoring rule distinguish a normal diagnostic binary from an unknown binary solely by behavior?

Record test scope, target ownership, timestamps, and observed results in your lab notes. Do not use this project to access or evade controls on systems without authorization.
